# weather 天气插件 · 适配文档

> 适配目标：银狼桌宠（Silver Wolf Desktop Pet）v0.6.20
> 插件版本：v1.0.0　|　编写日期：2026-11-24
> 对应文件：`plugin.json` / `main.py` / `README.md` / `技术路线.md` / 本文件

---

## 1. 适配目标与前置条件

查当前天气和未来预报，用 Open-Meteo 公共 API，**免 API key**。纯文本工具插件，不输出 `intent_payload`。

前置条件：

- 能访问 `api.open-meteo.com`（国内网络偶尔不通，见第 7 节降级）。
- 只用标准库 `urllib.request` / `json`，**不需要 pip 装 requests**。
- 城市名走内置坐标表；表外城市可传 `latitude` + `longitude`。

## 2. 本插件的返回字段

hello：

```json
{"t":"reply","ok":true,"intents":["weather","天气","气温","forecast"],"description":"查当前天气和未来预报，Open-Meteo 免 API key"}
```

ask 成功（实测样例）：

```json
{"t":"reply","ok":true,"text":"北京现在晴，4.3°C……","city":"北京","current":{...},"daily":[...]}
```

ask 参数不全时：

```json
{"t":"reply","ok":false,"error":"请给 city 或 latitude + longitude"}
```

网络失败时（**不是崩溃**）：

```json
{"t":"reply","ok":true,"text":"联网查天气失败，可能是网络不通：...","degraded":true}
```

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `text` | str | **宿主必用**，进气泡；失败时也是友好提示 |
| `degraded` | bool | 为 true 表示走了降级分支，宿主可据此不重试 |
| `city` | str | 城市名 |
| `current` / `daily` | dict/list | 结构化天气数据，宿主要做展示时用 |

支持参数：`city`（中文城市名）、`latitude` + `longitude`、`days`（预报天数）。

## 3. 宿主接入点与字段映射

| 插件字段 | 宿主函数（v0.6.20 真实位置） | 处理方式 |
| --- | --- | --- |
| `text` | `pet.py:773 show_bubble(text)` | 直接传入 |
| `degraded` | 无对应函数 | 宿主可选：为 true 时不反复重试，避免刷屏 |

**没有 `intent_payload`**：宿主只需要 `show_bubble`。如果以后要把天气做成看板卡片，可读 `current` / `daily` 自行渲染。

## 4. 状态文件与路径

无持久化状态。不缓存天气结果，每次调用实时查询（网络失败就走降级）。

## 5. 接入步骤

1. 把 `plugins/weather/` 拷进桌宠 `plugins/`，重启并启用（id=`weather`）。
2. 确认能联网；国内网络不稳时优先传坐标而不是城市名（少一次本地解析）。
3. 问"北京天气"→ 宿主应把 `weather` 意图路由过来。
4. 若想查境外城市，传 `{"latitude":35.68,"longitude":139.69}` 这类坐标。

## 6. 验证方法

```bash
cd plugins/weather
echo '{"t":"hello"}' | python main.py
echo '{"t":"ask","id":"1","intent":"weather","args":{"city":"北京"}}' | python main.py
echo '{"t":"ask","id":"2","intent":"weather","args":{}}' | python main.py
```

预期：第一条返回 intents；第二条返回真实天气或 `degraded:true`；第三条返回 `ok:false` + 中文错误。**三条都必须是单行 JSON**。

> 实测记录：2026-11-24 首次测试时本机到 Open-Meteo 的 SSL 握手超时，走降级；稍后复测网络恢复，拿到真实数据（北京晴 4.3°C）。两种情况都验证过。

## 7. 边界与降级

- **网络不通时不返回 `ok:false`**，而是 `ok:true + degraded:true + 友好文字`，避免桌宠报"插件坏了"。
- 本插件**不用**和风天气 API key（开发说明第 9 节里那个模板用和风），因此不需要用户注册账号。
- 城市坐标表覆盖常见国内城市；表外城市必须给经纬度，否则返回错误提示。
- 宿主的插件加载器不在本机源码里，"宿主调用"部分为协议设计，未在本机宿主实测。
