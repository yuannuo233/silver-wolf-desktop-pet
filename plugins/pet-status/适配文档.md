# pet-status 状态查询 · 适配文档

> 适配目标：银狼桌宠（Silver Wolf Desktop Pet）v0.6.20
> 插件版本：v1.0.0　|　编写日期：2026-11-24
> 对应文件：`plugin.json` / `main.py` / `README.md` / `技术路线.md` / 本文件

---

## 1. 适配目标与前置条件

汇总桌宠当前状态（角色、心情、精力、主题、尺寸、跟随开关等），供宿主同步或多宠协同看板。**隐私设计：API Key / base_url / model 一律不返回。**

前置条件：

- 银狼桌宠的 `%APPDATA%\SilverWolfPet\config.json` 存在（不存在时按默认处理）。
- 宿主只读 `status`，不回写配置。

## 2. 本插件的返回字段

hello（实测意图）：`["pet_status","状态","status","在干嘛", ...]`。

ask（实测）：

```json
{
  "t": "reply", "ok": true,
  "text": "她现在：当前角色 silver_wolf，心情平静，精力 77/100，主题 light",
  "status": {
    "character": "silver_wolf", "mood": "calm", "energy": 77, "theme": "light",
    "size_height": 200, "follow_activity": true,
    "last_behavior_at": 1795512189.98, "checked_at": "2026-11-24T17:23:11+08:00",
    "safe_config": {"theme":"light","size_height":200,"follow_activity":true,
                    "check_updates":true,"character":"","terms_seen":true}
  },
  "intent_payload": {"type":"pet_status","mood":"calm","character":"silver_wolf"}
}
```

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `text` | str | 气泡文字 |
| `status.character` | str | 当前角色 id |
| `status.mood` / `energy` | str/int | 来自 pet-emotion |
| `status.safe_config` | dict | **白名单过滤后**的配置，绝不含密钥 |
| `intent_payload.type` | str | 固定 `pet_status` |

## 3. 宿主接入点与字段映射

| 插件字段 | 宿主函数（v0.6.20 真实位置） | 处理方式 |
| --- | --- | --- |
| `status.character` | `characters.py:84 get(id)` / `config.py` 的 `character` 键 | 只读，不回写 |
| `status.safe_config.theme` | `config.py:37 load()` 的 `theme` | 白名单字段之一 |
| `status.*` | 无对应函数 | 宿主可渲染到「插件」页做状态面板 |
| `text` | `pet.py:773 show_bubble(text)` | 直接传入 |

**没有动画意图**：`intent_payload` 只是状态摘要，宿主不需要 `play_action()`。

**隐私白名单**（`main.py:12 _safe_conf()`）：只返回 `theme` / `size_height` / `follow_activity` / `check_updates` / `character` / `terms_seen`；`api_key` / `base_url` / `model` 被明确排除。宿主若以后要扩展字段，必须同步维护白名单，不能改成"整个 config 直接返回"。

## 4. 状态文件与路径

只读，不写自己的状态。读取：

- `%APPDATA%\SilverWolfPet\config.json`（白名单过滤）
- `%APPDATA%\SilverWolfPet\plugins\pet-emotion\emotion.json`
- `%APPDATA%\SilverWolfPet\plugins\pet-companion\companion.json`
- `%APPDATA%\SilverWolfPet\plugins\pet-character\character.json`

## 5. 接入步骤

1. 拷 `plugins/pet-status/` 到桌宠 `plugins/`，重启启用（id=`pet-status`）。
2. 问"你在干嘛"→ 返回状态气泡。
3. 宿主可把 `status` 渲染成面板；**不要**把 `safe_config` 之外的内容发给 AI 或网络。
4. 若扩展了桌宠配置字段，先评估隐私再决定是否加进白名单。
5. 状态文件都不存在时返回默认值 + 提示，不会崩。

## 6. 验证方法

```bash
cd plugins/pet-status
echo '{"t":"hello"}' | python main.py
echo '{"t":"ask","id":"1","intent":"pet_status","args":{}}' | python main.py
```

预期：输出里**搜不到** `api_key` / `base_url` / `model` 的实际值（字段名也不出现在 `safe_config` 里）。这是必须验证的隐私点。

## 7. 边界与降级

- **只返回白名单配置**，这是硬约束。任何"把 config 全返回"的改动都是隐私回归。
- 是**快照**不是订阅：每次调用读当前文件，不做事件推送。
- 不修改任何状态，所以"同步"是单向的（从插件/桌宠读出），宿主要改状态得走对应插件。
- 本机源码没有 `plugins_engine.py`，宿主调用链为协议设计，未在本机实测。
