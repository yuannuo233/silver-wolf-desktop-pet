# pet-dashboard 数据看板 · 适配文档

> 适配目标：银狼桌宠（Silver Wolf Desktop Pet）v0.6.20
> 插件版本：v1.0.0　|　编写日期：2026-11-24
> 对应文件：`plugin.json` / `main.py` / `README.md` / `技术路线.md` / 本文件

---

## 1. 适配目标与前置条件

把时间、待办、情绪、角色聚合成一条播报。做成**只读聚合器**：读其他插件的状态文件，自己不写状态。

前置条件：

- `reminder` / `pet-emotion` / `pet-character` 插件用过，否则对应字段为空（不会报错）。
- 天气**不在这里查**——看板只做本地聚合，要天气请单独调 `weather` 插件（开发说明的协议是一次一问一答，插件之间不互相调用）。

## 2. 本插件的返回字段

hello（实测意图）：`["dashboard","看板","今日","日报", ...]`。

ask（实测）：

```json
{
  "t": "reply", "ok": true,
  "text": "现在是 11月24日 17:23，星期二。她心情不错。待办清空了，今天很轻松",
  "summary": {"time":"2026-11-24T17:23:10+08:00","todos":[],"emotion":"calm","character":null},
  "intent_payload": {"type":"dashboard","brief":"（同 text）"}
}
```

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `text` | str | 气泡文字（完整播报） |
| `summary.time` | str | ISO 时间 |
| `summary.todos` | list | 待办列表（来自 reminder 的 SQLite） |
| `summary.emotion` | str | 当前心情（来自 pet-emotion） |
| `summary.character` | str/null | 当前角色（来自 pet-character） |
| `intent_payload.type` | str | 固定 `dashboard` |
| `intent_payload.brief` | str | 播报文案（等于 text） |

## 3. 宿主接入点与字段映射

| 插件字段 | 宿主函数（v0.6.20 真实位置） | 处理方式 |
| --- | --- | --- |
| `text` / `brief` | `pet.py:773 show_bubble(text)` | 直接传入即可，**这是主要用法** |
| `summary` | 无对应函数 | 宿主可选：渲染成看板窗口 |

**没有动画意图**：`intent_payload` 只是把文案再包一层，宿主不需要调 `play_action()`。这一点和 `pet-actions` / `pet-physics` 不同，别搞混。

## 4. 状态文件与路径

不写自己的状态。读取以下路径（都不存在时按空处理）：

- `%APPDATA%\SilverWolfPet\plugins\reminder\reminders.db`
- `%APPDATA%\SilverWolfPet\plugins\pet-emotion\emotion.json`
- `%APPDATA%\SilverWolfPet\plugins\pet-character\character.json`

## 5. 接入步骤

1. 拷 `plugins/pet-dashboard/` 到桌宠 `plugins/`，重启启用（id=`pet-dashboard`）。
2. 问"今天怎么样"→ 宿主路由 `dashboard` 意图，返回一条完整播报。
3. 宿主只需 `show_bubble(r["text"])`；不需要物理层或动作层。
4. 若想加天气，宿主先调 `weather` 再把结果拼进气泡——插件之间不互相调用。
5. 首次使用前其他插件没数据时，播报会跳过对应部分，不会报"文件不存在"。

## 6. 验证方法

```bash
cd plugins/pet-dashboard
echo '{"t":"hello"}' | python main.py
echo '{"t":"ask","id":"1","intent":"dashboard","args":{}}' | python main.py
```

预期：返回一条中文播报，`summary` 里各字段可能是 null / 空列表（正常），stdout 只有一行 JSON。先跑一遍 reminder 加个待办，再跑看板，应能看到 todos 非空。

## 7. 边界与降级

- **只读**：不会修改提醒、情绪、角色任何状态。
- 其他插件状态文件缺失 / 损坏时按空处理并在文案里弱化，不报错。
- 不包含天气（需单独调 weather），这是按协议做的职责划分，不是遗漏。
- 本机源码没有 `plugins_engine.py`，宿主调用链为协议设计，未在本机实测。
