# pet-companion · 技术路线

## 来源
按用户口述的桌宠陪伴需求设计：不让宠物机械地重复同一个待机循环，而是在看鼠标、歪头、眨眼、换重心、回头、发呆之间自然轮换，并配少量碎碎念台词。

> 说明：这是根据用户描述的功能需求做的意图层设计，本地没有参考项目源码，未逐项核对其内部实现。

## 行为表
7 个自主行为：look_mouse / tilt_head / blink / shift_weight / glance_back / daydream / small_smile
7 句碎碎念：从日常关心到傲娇吐槽，模仿银狼人设。

## 去重算法
```
idx = random(len)
if idx == last_idx: idx = (idx + 1) % len
```
简单但有效：保证连续两次不同，又不引入复杂调度。

## 为什么"低频"由宿主控制
插件是一问一答，不知道"多久算低频"。所以本插件只管"给一个不重复的行为"，调用频率由宿主决定（建议 30~120 秒随机间隔）。状态里的 `last_at` 是时间戳，宿主可以用来判断间距。

## 它能做什么 / 不能做什么
- ✅ 行为轮换、去重、碎碎念、输出意图
- ❌ 不检测鼠标位置（那是宿主的 `pet.py` 干的）
- ❌ 不自己定时触发

## 宿主接入
- `intent_payload.type=companion_action` → 播对应微动作（若素材没有，用气泡文字代替）
- `type=companion_chatter` →  Bubble 显示台词

## 已知边界
- 行为是预设列表，不会学习用户习惯；要"记住你喜欢什么"得另做模型。
- 碎碎念是固定台词库，非 AI 生成；要真聊天用桌宠自带的 AI 聊天功能。
