# clock 报时插件 · 适配文档

> 适配目标：银狼桌宠（Silver Wolf Desktop Pet）v0.6.20
> 插件版本：v1.0.0　|　编写日期：2026-11-24
> 对应文件：`plugin.json` / `main.py` / `README.md` / `技术路线.md` / 本文件

---

## 1. 适配目标与前置条件

把当前时间（含时区、星期）以气泡文字形式播报出来。这是纯文本工具插件，**不输出 `intent_payload`**，不需要宿主做额外动作。

前置条件：

- 宿主按 `插件开发说明(1).md` 的协议调用插件（stdin 一行 JSON，stdout 一行 JSON）。
- 宿主把返回的 `text` 显示到桌宠气泡。对应本机源码 `pet.py:773 show_bubble(text, duration_ms)`。
- 无第三方依赖，只用标准库 `datetime` / `zoneinfo`。Windows 上 `zoneinfo` 需要系统时区数据库；Win10 1809+ 自带，旧系统可 `pip install tzdata`。

## 2. 本插件的返回字段

hello（握手）：

```json
{"t":"reply","ok":true,"intents":["clock","time","报时","时间"],"description":"告诉她现在几点"}
```

ask（实测样例，北京时间 2026-11-24 17:23）：

```json
{
  "t": "reply", "ok": true,
  "text": "现在是 2026年11月24日 17:23:08，星期二（中国标准时间）",
  "iso": "2026-11-24T17:23:08+08:00",
  "timezone": "中国标准时间",
  "timestamp": 1795512188
}
```

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `text` | str | **宿主必用**，直接进气泡 |
| `iso` | str | ISO 8601 带时区，宿主要做时间计算时用 |
| `timezone` | str | 时区中文名 |
| `timestamp` | int | Unix 秒级时间戳 |

支持的 `args`：`tz`（IANA 时区名，如 `Asia/Shanghai`、`UTC`）、`format`（预留）。不传 `tz` 时取本机本地时区。

## 3. 宿主接入点与字段映射

| 插件字段 | 宿主函数（v0.6.20 真实位置） | 处理方式 |
| --- | --- | --- |
| `text` | `pet.py:773 show_bubble(text, duration=BUBBLE_MS)` | 直接传入即可，无需解析其他字段 |
| `iso` / `timestamp` | 可选，宿主若做日程联动可用 | 不接也不影响基本功能 |

**没有 `intent_payload`**：这是有意的。协议里 `text` 是原生字段，工具型插件没必要额外发明意图。宿主读到 `t=reply & ok=true` 后只需要 `show_bubble(r["text"])`。

## 4. 状态文件与路径

无状态。每次调用实时读系统时钟，不写任何文件。

## 5. 接入步骤

1. 把 `plugins/clock/` 整个文件夹拷进银狼桌宠的 `plugins/` 目录。
2. 重启桌宠 →「插件」页 → 启用「报时」（`id=clock`）。
3. 确认 `plugin.json` 的 `id` 没有被别的插件占用。
4. 在聊天框问"现在几点"，宿主应把 `intents` 里的 `clock` / `time` 路由到本插件。
5. 若宿主没有意图路由，可先直接测命令行（见第 6 节），确认插件本身可用。

## 6. 验证方法

命令行自测，不启动桌宠：

```bash
cd plugins/clock
echo '{"t":"hello"}' | python main.py
echo '{"t":"ask","id":"1","intent":"clock","args":{"tz":"Asia/Shanghai"}}' | python main.py
```

预期：stdout **只有一行**合法 JSON，中文正常显示（不是 `\uXXXX`）。

宿主内验证：问"几点了"→ 气泡出现完整时间；问"UTC 几点"→ 返回 UTC 时间且 `timezone` 为 UTC。

## 7. 边界与降级

- 时钟取系统时间，**系统时间不准则结果不准**，插件不联网校时。
- 传入未知时区名时 `ZoneInfo` 抛异常，最外层 try/except 返回 `ok:false` + 错误文字，不会崩溃或污染 stdout。
- 本机 `silver-wolf-desktop-pet-source` 里没有 `plugins_engine.py`（插件加载器在说明文档指向的 `F:\银狼\上传源码`），所以"宿主调用"部分是**按协议设计的接入方案，未在本机宿主实测**。插件本身已用第 6 节方法验证。
