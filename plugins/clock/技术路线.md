# clock · 技术路线

## 数据来源
`datetime.now().astimezone()` 取本机带时区的当前时间。时区转换用标准库 `zoneinfo`（Python 3.9+）。

## 处理流程
1. 读一行 stdin → `json.loads`。
2. hello 分支返回 `intents` 列表。
3. ask 分支取 `args.timezone`（兼容 `args.tz`）：
   - 空 / local → 本机时区
   - UTC → `timezone.utc`
   - IANA 名 → `ZoneInfo(name)`，名字无效则回退本机并在 label 里注明
4. 星期用 `weekday()` 索引映射到中文，不依赖 locale。
5. 返回一行 JSON。

## 为什么这样设计
- 不用 `time.strftime("%A")` 拿英文名再翻译——locale 在不同机器上不一致，直接索引最稳。
- 时区无效不报错，降级到本机时间并说明——气泡是给用户看的，不该因为一个参数写错就显示"出错了"。

## 已知边界
- IANA 时区数据库依赖系统；极简 Linux 容器可能没有 tzdata，届时 `ZoneInfo` 抛异常，已兜底回退本机。
- 返回的时间是调用瞬间，不是持续的时钟；要做状态栏常驻显示需宿主自己定时调用。

## 与 MCP 原版的关系
原 MCP 工具的 `get_current_time` 逻辑完整复用，只换了外层协议（FastMCP 装饰器 → 一行 JSON）。
