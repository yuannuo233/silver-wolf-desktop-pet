# pet-physics · 技术路线

## 来源
按用户口述的桌宠互动需求设计：点击 Q 弹回嘴、拖拽甩抛后沿屏幕边缘物理反弹。这两项需要物理引擎，插件层只能描述意图。本地没有参考项目源码，功能点为需求描述，未逐项核对。

## 意图结构
```json
{"type": "physics", "event": "edge_bounce", "intensity": 0.8,
 "velocity": {"x": 300, "y": -200, "speed": 360.55},
 "restitution": 0.8}
```
- `event`：效果类型（bounce / drag / throw / drop / edge_bounce / shake）
- `intensity`：0~1，强度
- `velocity`：速度向量与标量速度（throw/drop/edge_bounce 才有）
- `restitution`：弹性系数 = 0.4 + 0.5 × intensity

## 为什么弹性系数这么算
0.4 是下限（软趴趴），0.9 是上限（很弹）。和 intensity 线性挂钩，宿主不用再自己换算。速度用 `math.hypot` 语义（这里手写 sqrt 避免版本差异）。

## 它能做什么 / 不能做什么
- ✅ 事件归一（中文别名 → 英文 event）、物理参数计算、气泡台词
- ❌ 不修改桌宠窗口坐标（插件进程拿不到 HWND）
- ❌ 不做碰撞检测（那是宿主的事）

## 宿主需要做什么
1. 解析 `intent_payload.event`。
2. `bounce` → 触发缩放回弹动画（如 1.0→1.15→1.0）。
3. `throw` / `edge_bounce` → 按 `velocity` 做位移积分，撞边界时乘 `restitution` 反向。
4. `shake` → 左右抖动若干帧。

## 已知边界
- 没有重力/摩擦模拟，只有参数；宿主按需加。
- 速度单位未规定（像素/秒是常见选择），宿主自行解释。
