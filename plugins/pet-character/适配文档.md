## 1. 适配目标与前置条件

列出可用角色包、统计磁盘真实帧数、切换当前角色。这是 7 个行为插件里**唯一对照了本机真实源码**的一个：v0.6.20 新增的 `characters.py` 提供了角色包系统。

前置条件：

- 宿主要把 `SILVERWOLF_APP_DIR` 环境变量指向银狼桌宠源码根目录，否则插件找不到 `characters/` 和 `assets/stand/`。
- 角色包结构（据 `characters.py:7-19`）：`characters/<id>/character.json` + `stand/`（frames.json + PNG）。默认角色 `silver_wolf` 的素材在 `assets/stand/`。
- 切换角色写的是 `%APPDATA%\SilverWolfPet\plugins\pet-character\character.json`，**不是**直接改桌宠主配置；宿主需决定是否同步到 `config["character"]`。

## 2. 本插件的返回字段

hello（实测意图）：`["character","角色","换角色","characters", ...]`。

ask（list，在 bundle 目录直接跑——**找不到素材**时）：

```json
{"t":"reply","ok":true,"text":"现有角色：● 银狼（素材未就位）",
 "characters":[{"id":"silver_wolf","name":"银狼","frames":0,"builtin":true,
                "dir":"E:\\github\\银狼桌宠插件合集-v1.0.0\\assets\\stand"}],
 "current":"silver_wolf"}
```

用 `SILVERWOLF_APP_DIR` 指向真实源码后，实测 `frames` 正确识别为 **186**。

ask（switch）：

```json
{"t":"reply","ok":true,"text":"已选「银狼」，重启桌宠后生效",
 "character":{...},
 "intent_payload":{"type":"switch_character","id":"silver_wolf"}}
```

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `text` | str | 气泡文字 |
| `characters` | list | 角色列表，含 `id` / `name` / `frames` / `builtin` / `dir` |
| `current` | str | 当前角色 id |
| `intent_payload.type` | str | `switch_character` |
| `intent_payload.id` | str | 目标角色 id |

支持 `args`：`action`（`list` / `switch` / `current`）、`id`。

## 3. 宿主接入点与字段映射

| 插件字段 | 宿主函数（v0.6.20 真实位置） | 处理方式 |
| --- | --- | --- |
| `characters` 列表 | `characters.py:61 list_characters()` | 两处逻辑等价；宿主也可用自己的列表 |
| `frames` 统计 | 插件自己数 `stand/*.png` | `characters.py` 不提供帧数，这是插件补的能力 |
| `intent_payload.id` | `characters.py:84 get(id)` + `config.py:46 save(cfg)` | 写 `cfg["character"] = id` 后重启，或热切换 |
| `text` | `pet.py:773 show_bubble(text)` | 直接传入 |

**切换生效的两种方式**：

1. **重启生效**（插件默认行为）：宿主把 `intent_payload.id` 写进 `config.py` 的 `character` 键，下次启动 `get(id)` 加载。`characters.py:84` 对未知 id 自动回落默认角色，不会让桌宠开不起来。
2. **热切换**（需宿主实现）：`pet.character = characters.get(id)` 然后 `pet._load_sprite()` / `pet._load_anim()` 重新载入。v0.6.20 的角色页走的是"重启生效"，热切换要宿主自己加。

## 4. 状态文件与路径

- 当前角色：`%APPDATA%\SilverWolfPet\plugins\pet-character\character.json`
- 回退路径：`~/.config/SilverWolfPet/plugins/pet-character/`
- 素材根目录：由 `SILVERWOLF_APP_DIR` 指定；未指定时插件用自身 cwd，会显示"素材未就位"。

## 5. 接入步骤

1. 拷 `plugins/pet-character/` 到桌宠 `plugins/`，重启启用（id=`pet-character`）。
2. **设置 `SILVERWOLF_APP_DIR`** 指向银狼桌宠安装/源码目录，否则帧数永远是 0。
3. 问"有哪些角色"→ 应列出真实帧数（银狼默认应为 186）。
4. 问"换成 XXX"→ 插件写自己的状态文件；宿主读 `intent_payload.id` 同步到主配置。
5. 新角色包只要丢进 `characters/<id>/` 且 `character.json` 合法，插件自动列出，`characters.py:61 list_characters()` 也能识别——**不用改代码**。

## 6. 验证方法

```bash
cd plugins/pet-character
echo '{"t":"hello"}' | python main.py
echo '{"t":"ask","id":"1","intent":"character","args":{"action":"list"}}' | python main.py
SILVERWOLF_APP_DIR="E:/github/silver-wolf-desktop-pet-source"   sh -c 'echo "{"t":"ask","id":"2","intent":"character","args":{"action":"list"}}" | python main.py'
```

预期：第三条返回 `frames:186`（本机实测）；不带环境变量时 `frames:0` + "素材未就位"。两种都是**正确行为**，区别只在路径。

## 7. 边界与降级

- 角色包损坏 / `character.json` 非法 → `characters.py:40 _read_spec()` 返回空并跳过；未知 id → `:84 get()` 回落默认角色。桌宠始终能启动。
- 插件的"切换"只写自己的状态文件，**不会自动改变正在显示的桌宠**——宿主必须接 `intent_payload` 或重启。
- 插件只统计 `stand/*.png` 数量，不校验帧规格（190×216、二值透明等）；素材问题仍需作者自己检查。
- 宿主加载器不在本机源码里，宿主调用链为协议设计，未在本机实测。
