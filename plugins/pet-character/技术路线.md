# pet-character · 技术路线

## 来源
对标 v0.6.20 银狼桌宠新增的"角色页 + 角色包系统"（`characters.py`）：
- 一个角色 = `characters/<id>/` 文件夹 + `character.json`
- 帧数按磁盘实际文件统计，不读配置声明
- 素材没做完显示"素材未就位"
- 切换只写配置，重启生效

## 为什么要按磁盘数帧
v0.6.20 的原话："帧数按磁盘实际文件统计，不读配置声明 —— 素材没做完会老实显示「素材未就位」，不会骗你。" 这里完整复用这个设计：`glob("*.png")` 数文件，0 帧就在列表里标注并拒绝切换。

## 路径解析
插件文件在 `<app>/plugins/pet-character/main.py`：
- `.parent` = pet-character
- `.parent.parent` = plugins
- `.parent.parent.parent` = app 根 ✓

如果宿主把插件装在别处，可用 `SILVERWOLF_APP_DIR` 覆盖。这比硬编码 `F:\银狼` 可靠（那是文档作者的机器路径）。

## 它能做什么 / 不能做什么
- ✅ 扫描角色包、数帧、列当前角色、写切换配置、输出切换意图
- ❌ 不真正重载素材（需要宿主重启或调用 `characters.get()` 重新加载）
- ❌ 不创建/删除角色包（只读 + 切 id）

## 宿主接入
`intent_payload.type=switch_character` → 写宿主自己的 `config["character"]`，然后提示重启或热重载。

## 已知边界
- 默认角色素材在 `assets/stand/`，角色包素材在 `characters/<id>/stand/`，两种路径都支持。
- 角色包 `character.json` 损坏时按文件夹名当角色名，帧数照数，不会让列表崩。
