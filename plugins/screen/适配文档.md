# screen 截屏插件 · 适配文档

> 适配目标：银狼桌宠（Silver Wolf Desktop Pet）v0.6.20
> 插件版本：v1.0.0　|　编写日期：2026-11-24
> 对应文件：`plugin.json` / `main.py` / `README.md` / `技术路线.md` / 本文件

---

## 1. 适配目标与前置条件

截取主屏幕存 PNG，OCR 文字识别可选。纯文本工具插件，不输出 `intent_payload`。

前置条件：

- **截屏**：推荐装 `mss`（`pip install mss`）。没装时插件走 ctypes/Pillow 降级路径，实测在本机仍成功（见第 6 节）。
- **OCR**（可选）：需 `Pillow` + `pytesseract` + 系统 Tesseract。没装时返回明确提示，不崩。
- 多显示器环境截的是主屏；坐标按主屏左上角为原点。

## 2. 本插件的返回字段

hello：

```json
{"t":"reply","ok":true,"intents":["screenshot","截图","截屏","ocr","屏幕"],"description":"截取主屏幕存 PNG，OCR 文字识别可选（缺依赖时降级）"}
```

ask 成功（本机实测）：

```json
{
  "t": "reply", "ok": true,
  "text": "截图已保存到 C:\\Users\\...\\screen_20261124_172312.png",
  "path": "C:\\Users\\...\\screen_20261124_172312.png",
  "width": 3200, "height": 2000, "bytes": 806276, "via": "mss"
}
```

| 字段 | 类型 | 用途 |
| --- | --- | --- |
| `text` | str | **宿主必用**，进气泡（含保存路径） |
| `path` | str | PNG 绝对路径，宿主可据此打开文件 |
| `width` / `height` | int | 像素尺寸 |
| `bytes` | int | 文件字节数 |
| `via` | str | 实际用的截屏方式（`mss` 等） |

支持 `args`：`filename`（自定义文件名）、`out_dir`、`ocr`（true 时尝试识别）、`lang`（OCR 语言）。

## 3. 宿主接入点与字段映射

| 插件字段 | 宿主函数（v0.6.20 真实位置） | 处理方式 |
| --- | --- | --- |
| `text` | `pet.py:773 show_bubble(text)` | 直接传入，含路径 |
| `path` | 无对应函数 | 宿主可选：提供"打开截图"入口 |

**没有 `intent_payload`**。隐私提示：截图会存到磁盘，路径在气泡里可见，不要误把含敏感信息的屏幕截图发到聊天——插件**不外传**，但宿主若把 `path` 交给 AI 插件就另当别论。

## 4. 状态文件与路径

- 截图目录：`%APPDATA%\SilverWolfPet\plugins\screen\screenshots\`
- 文件名默认 `screen_YYYYMMDD_HHMMSS.png`
- 环境变量缺失时回退到 `~/.config/SilverWolfPet/plugins/screen/`
- 插件只写截图文件，不维护索引数据库。

## 5. 接入步骤

1. 拷 `plugins/screen/` 到桌宠 `plugins/`，重启启用（id=`screen`）。
2. 建议 `pip install mss`，截屏更快更稳。
3. 问"截个屏"→ 插件存图并返回路径气泡。
4. OCR 是可选能力：传 `{"ocr":true}`，缺 Tesseract 时会返回"请安装"提示而非崩溃。
5. 定期清理 `%APPDATA%\...\screen\screenshots\`，插件不自动删旧图。

## 6. 验证方法

```bash
cd plugins/screen
echo '{"t":"hello"}' | python main.py
echo '{"t":"ask","id":"1","intent":"screenshot","args":{}}' | python main.py
```

预期：返回一行 JSON，`path` 是真实存在的文件，`via` 说明走哪条截屏路径。本机 2026-11-24 实测：`via=mss`，3200×2000，806276 字节，成功。

## 7. 边界与降级

- 无图形会话（如纯 SSH）下截屏会失败，插件返回 `ok:false` + 错误文字，不崩。
- 缺 `mss` 时走 ctypes/Pillow 降级；两者都没有时明确提示安装，不假装成功。
- OCR 缺依赖时返回友好提示，**不会**把截图内容外传。
- 宿主的插件加载器不在本机源码里，"宿主调用"部分为协议设计，未在本机宿主实测。
